# Triage 标签

各技能使用五种规范的 triage 角色。下表将这些角色映射到本仓库 Issue Tracker 中实际使用的标签字符串。

| `mattpocock/skills` 中的角色 | 本仓库标签              | 含义                           |
| ---------------------------- | ----------------------- | ------------------------------ |
| `needs-triage`               | `needs-triage`          | 等待维护者评估该 issue         |
| `needs-info`                 | `needs-info`            | 等待报告者补充信息             |
| `ready-for-agent`            | `ready-for-agent`       | 规格完整，可交给无人值守 agent |
| `ready-for-human`            | `ready-for-human`       | 需要由人工实现                 |
| `wontfix`                    | `wontfix`               | 不会处理                       |

当技能提到某个角色（例如“应用可交给无人值守 agent 的 triage 标签”）时，使用表中对应的标签字符串。

若本仓库以后采用不同标签词汇，请编辑右侧“本仓库标签”列。
